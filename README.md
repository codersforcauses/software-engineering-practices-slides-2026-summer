# Software Engineering Practices - CFC Summer 2026

Talk slides on what software engineering looks like now that AI writes much of the code, for the Coders for Causes Summer 2026 program.

## Topics

- Part 1: The role of a software engineer
- Part 2: How to break down problems
- Part 3: How to implement
- Interlude: Git basics and remotes
- Part 4: Avoiding slop
- Part 5: Why learning software is hard
- Part 6: How I work

## Running locally

```bash
npm install
npm start
```

Then open [http://localhost:8000](http://localhost:8000) in your browser.

## Slide images

Images are referenced without a file extension (e.g. `img/utopia`). Add a file with that name as `.svg`, `.png`, `.jpg`, `.jpeg`, `.webp` or `.gif` and the slide picks it up; until then a labelled placeholder is shown.
