# Practical Software Engineering - CFC Winter 2026

Workshop slides covering teamwork, agile practices, and git for the Coders for Causes Winter 2026 program.

## Topics

- Working in teams vs working alone
- Planning work with cards and boards
- Git fundamentals: commits, branches, merges, and remotes

## Running locally

```bash
npm install
npm start
```

Then open [http://localhost:8000](http://localhost:8000) in your browser.
